# 번역 원칙

## 문체

독송할 때 호흡이 자연스럽도록 한 문장을 지나치게 길게 만들지 않는다. 존칭은 `세존`, 대화 상대는 `수보리여`로 통일한다. 불필요한 한자어는 풀어 쓰되, 뜻이 크게 달라지는 핵심 용어는 괄호나 번역 주에서 원어를 제시한다.

## 핵심 용어

| 원어 | 한역 | 이 번역의 기본 표현 |
| --- | --- | --- |
| Bhagavān | 世尊 | 세존 |
| Tathāgata | 如來 | 여래 |
| bodhisattva | 菩薩 | 보살 |
| prajñāpāramitā | 般若波羅蜜 | 지혜의 완성(반야바라밀) |
| saṃjñā | 相 / 想 | 관념, 알아보고 표상하는 작용 |
| lakṣaṇa | 相 | 특징, 표지, 모습 |
| nimitta | 相에 포함되어 번역되기도 함 | 표지, 표상 |
| dharma | 法 | 문맥에 따라 가르침, 현상, 마음의 대상 |
| pratiṣṭhita | 住 | 머무르다, 의지하다 |
| dāna | 布施 | 베풂, 보시 |
| nirvāṇa | 涅槃 | 열반 |

`saṃjñā`는 문맥에 따라 단순한 외형보다 ‘무엇이라고 규정하여 붙잡는 관념’에 가깝다. 따라서 독송 본문에서는 전통적인 `상`을 살리되, 처음 나올 때 뜻을 풀어 준다.

한문 `相`을 언제나 하나의 산스크리트 단어로 환원하지 않는다. 제3·6분의 관념, 제4분의 `nimittasaṃjñā`, 제5·20·26분의 신체적 특징 등을 구별하고, 같은 한국어를 사용하더라도 원어의 차이를 번역 주와 `SOURCES.md`에 남긴다.

## 판본 차이 처리

본문은 산스크리트와 구마라집본이 공유하는 뜻을 중심으로 번역한다. 중요한 차이는 `번역 주`에 기록한다. 구마라집본의 간결함을 존중하지만, 그 때문에 수행의 주체나 문장의 관계가 모호해질 때에는 산스크리트 문장을 참고해 자연스럽게 보완한다.

이 번역은 한문과 산스크리트를 대조한 한국어 번역이다. 한문만의 직역으로 표시하지 않는다. 산스크리트에만 있는 문장·동작·수식어를 본문에 채택했다면 해당 분의 번역 주에서 그 사실을 밝힌다. 한문 섹션에는 그런 보충을 넣지 않는다.

`고정된`은 원문에 언제나 명시되어 있는 단어가 아니다. 실체화와 집착을 설명하기 위해 덧붙인 해석적 표현이며, `非·無`를 일률적으로 이 말 하나로 풀 수는 없다. 대응하는 부정어, 인식·취득 동사, 문장 관계를 구절별로 검토하고 보충의 근거를 `SOURCES.md`에 남긴다.

부정문에 `붙잡는다면` 같은 조건을 새로 넣어 부정의 범위를 좁히지 않는다. `無實無虛 / na satyaṃ na mṛṣā`처럼 원문의 대구가 분명한 곳은 직접 부정을 우선하고 실체화 부정이라는 해설은 번역 주로 분리한다. `고정된`의 유지·삭제는 일괄 치환이 아니라 해당 문맥에 따라 판단한다.

산스크리트의 여래·아라한·정등각자 존칭이 한 대상을 가리키는 동격 열거일 때에는 별개의 수혜자 집단처럼 번역하지 않는다. C와 S의 차이는 `C에는… S에는…`으로 기술하고, 문구 차이만으로 한쪽이 다른 쪽을 역사적으로 생략·확장했다고 단정하지 않는다. 전자본의 부정어 누락이나 구두점이 의심스러우면 실제 표기를 남기고 다른 판본 대조 전까지 판정을 유보한다.

`SOURCES.md`와 여기서 연결한 `review/`의 분별 검토표에는 한문과 산스크리트 대응어, 채택한 번역과 이유, 다른 가능성, 배경 자료, 정확한 판본, 확인일과 URL을 누적한다. 지정 전자본 전 구절 검토와 다른 사본을 포함한 비평적 교감은 구별하고, 확인하지 않은 자료는 남은 과제로 표시한다.

## 문서 순서와 현토

각 분은 `한글 번역 → 번역 주 → 한문과 현토 독음` 순서로 구성한다.

`한문과 현토 독음`에서는 문장이나 의미 단위마다 굵은 한문을 먼저 싣고, 바로 다음 줄에 순한글 현토 독음을 둔다. 인용 블록이나 반복되는 라벨은 사용하지 않는다.

굵은 한문에는 구마라집 원문의 모든 한자를 원래 순서대로 보존한다. 현토 독음은 모든 한자를 한국 한자음으로 읽고 문장의 구조와 독송 호흡을 드러내는 조사와 어미를 덧붙인다. `般若`의 `반야`, `須菩提`의 `수보리`처럼 불교에서 굳어진 관용음을 우선한다. 현대어 완역으로 바꾸거나 원문에 없는 교리 해설을 현토 독음 안에 넣지 않는다.

한문 기준은 CBETA T235의 교감 주본문이다. 제목·역자 표시·권말 부가 진언을 제외하고 설법의 산문과 게송을 수록한다. 표점과 문단 나눔은 독송 호흡에 따라 달리할 수 있지만, `然/燃`, `則/即`과 같은 글자를 임의로 통일하지 않는다. 원문 확인에는 `uv run python scripts/verify_translation.py --cbeta`를 사용할 수 있다.
