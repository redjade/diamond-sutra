# 金剛經 금강경 전 구절 검토 목록

확인일: **2026-10-16**. 2차 교정: **2026-10-30**.

제1분부터 제32분까지 한글 번역의 모든 문장과 대응 한문·산스크리트를 대조했다. 검토표는 총 427개의 의미 단위로 구성한다. 짧은 문답은 한 행으로, 긴 문장·목록·이유절은 여러 행으로 나누기도 하므로 이 숫자는 원문의 절 수를 뜻하지 않는다.

검토 기준은 [SOURCES.md](../SOURCES.md)의 C(CBETA T235 고정 커밋)와 S(GRETIL Vaidya본)이다. 각 분의 표에 실제 확인일, URL, 한문 위치와 S 절 번호를 적었다. 인쇄본·전체 사본까지 대조한 비평적 교감은 아니며, 미해결 독법은 유보로 남겼다.

## 검토 방법

- 원문의 모든 구절과 한글 번역을 순서대로 대조하고, 주어·대상·시제·수량·당위·조건·부정의 범위와 문장 관계를 확인했다.
- C에만 있거나 S에만 있는 내용은 따로 기록했다. 전자본의 실제 표기와 문맥상 기대되는 독법을 구별하고, 의심되는 글자를 무단으로 보정하지 않았다.
- 본문에 추가된 해석과 산스크리트 보완을 구별했다. 수정하지 않은 문장도 유지 이유를 기록했다.
- 한문은 변경하지 않았다. 굵은 한문 5,129자를 지정 CBETA 본문과 대조하는 검사, 문서 구조·한문과 현토 독음의 짝 검사를 별도로 시행했다. 이 자동 검사는 의미 검토를 대신하지 않는다.

## 결과와 한계

25개 분의 번역 또는 번역 주를 교정했다. 제12·18·20·23·26·27·29분은 대응과 판본 차이를 검토한 뒤 본문을 유지했다. 주요 교정은 원문에 없는 조건·수식어 삭제, 직접 부정 복원, 보시 수혜자의 동격 존칭, 수량·시간 표현의 판본별 분리다.

2026-10-30 2차 교정에서는 19개 분의 번역 또는 번역 주를 다시 고쳤다. 같은 `即非…是名…`·`實無有法`·`無我` 구문을 분마다 다르게 옮기던 것을 직접 부정으로 통일하여 `고정된`을 제7분의 `定法` 대응 두 곳만 남겼다. 그 밖에 `如來說非X`의 어순(제23·31분), 제12분 본문과 주석의 불일치, 제13분의 자기 존대, 제17분 번역 주의 S 인용 오류, 제10분 `清淨心`·`無所住` 대응, 주석에 밝히지 않은 S 보완, 분 안의 `관념`·`상` 혼용을 바로잡았다. 각 분 검토표 끝의 `2차 교정` 절이 위 표의 해당 행보다 우선한다.

수정은 끝났어도 모든 해석이 확정된 것은 아니다. 특히 제9·13분 전자본의 부정어 표기, 제12분 구문, 제17분 `dharmoccheda`, 제27분 부정 구조, 제28분 두 수용 동사의 구별, 제32분 끝부분의 구두점은 [유보 목록](../SOURCES.md#전-구절-검토에서-남긴-유보)과 각 분의 기록을 함께 읽는다. 다른 교정본·사전·논서 대조와 현토 문체 통일은 후속 과제다.
