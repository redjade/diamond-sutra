# 제8분 전 구절 검토

- 검토일: 2026-10-16. 대상: [번역·주석·현토 전체](../translation/08-uibeop-chulsaeng.md).
- C: [CBETA T235 고정본](https://github.com/cbeta-org/xml-p5/blob/dbdea41071e1e260ad84b72faefd4587333cf76d/T/T08/T08n0235.xml), 0749b18–25.
- S: [GRETIL Vaidya 전자본](https://gretil.sub.uni-goettingen.de/gretil/1_sanskr/4_rellit/buddh/bsu051_u.htm), §8, 표시 쪽 77.

| 구절 | S 대응 표지 | 판정과 번역 판단 |
| --- | --- | --- |
| 須菩提於意云何若人 | tat kiṃ manyase, kulaputra, kuladuhitṛ | S 보완 명시. 선한 남자·여자는 S에 명시되어 있어 반영하고 C의 일반적 `사람`과 구별했다. |
| 滿三千大千世界七寶 | trisāhasramahāsāhasra lokadhātu, saptaratna | 유지. 세계를 가득 채우는 보물의 양이지 단순히 삼천 개의 세계라는 뜻으로 풀지 않는다. |
| 以用布施 | dāna, tathāgata, arhat, samyaksaṃbuddha | 교정. 수혜자를 `여래와 성자들`에서 `여래들`로 고쳤다. 나열된 존칭을 별도 집단으로 분리하지 않으며 S의 보완임을 주석에 표시한다. |
| 是人所得福德寧為多不 | puṇyaskandha prasunuyāt | 유지. 그 보시로 생기는 복덕의 양을 묻는 가정문이다. |
| 須菩提言甚多世尊 | bahu bhagavan, bahu sugata | 유지. 긍정 답변. S의 존칭 반복은 압축했다. |
| 是福德即非福德性 | puṇyaskandha, askandha | 교정. C의 `性`을 살려 `복덕의 본성이 아니다`로 옮겼다. S의 무더기 부정과 구별한다. `실체로서의`라는 해설을 본문에서 덜었다. |
| 是故如來說福德多 | S는 puṇyaskandha의 명명 | 교정. 한국어에 빠졌던 C의 `많다`를 되살렸다. S의 명명은 주석에서 다룬다. |
| 若復有人於此經中受持 | dharmaparyāya, udgṛhya | 유지. 비교되는 다른 사람과 받아 지님을 보존한다. |
| 乃至四句偈等 | antaśas, catuṣpādikā gāthā | 유지. 최소한 네 구절 게송 하나라도라는 양보적 범위. 마지막 게송만으로 한정하지 않는다. |
| 為他人說其福勝彼 | deśayet, saṃprakāśayet, bahutara | S 보완 유지. 자세히 설명함·큰 복덕과 헤아림 불가를 S에서 보완했다. 비교 대상은 앞의 보시다. |
| 一切諸佛及…菩提法皆從此經出 | atonirjāta, buddha, anuttarā samyaksaṃbodhi | 유지. 부처들과 그 깨달음의 출처라는 C/S 공통 관계를 살렸다. 한국어에서 `가르침`은 이 법문을 가리킨다. |
| 所謂佛法者即非佛法 | buddhadharma, abuddhadharma | 교정·해석 유보. `부처의 가르침`을 `부처의 법`으로 열어 두었다. 가르침과 부처를 이루는 특성이라는 의미 범위를 더 검토할 수 있다. |
| S의 마지막 명명문 | tenocyante buddhadharmāḥ | 판본 구별·교정. C에는 없는 명명문을 한국어 본문에서도 덜고 번역 주에 남겼다. |

한문·현토 7쌍을 확인했다. 이 분의 `고정된` 2회와 `고정된 실체로서의`라는 부연을 덜었다. `福德性`·`佛法`은 단어만으로 뜻이 완전히 확정되지 않으므로 선택과 대안을 모두 기록한다.
