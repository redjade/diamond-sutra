# <a name="top"></a>제29분 위의적정분(威儀寂靜分) — 오고 감 없는 고요한 몸가짐

## <a name="translation"></a>한글 번역

세존께서 말씀하셨다.

“수보리여, 어떤 사람이 ‘여래가 오기도 하고 가기도 하며, 앉기도 하고 눕기도 한다’고 말한다면, 그는 내가 말한 뜻을 이해하지 못한 것이다.

왜 그런가? 여래는 어디에서 온 것도 아니며 어디로 가는 것도 없기에 여래라 부르기 때문이다.”

## <a name="notes"></a>번역 주

1. <a name="c29-note-01"></a>`威儀`는 걷고 서고 앉고 눕는 일상의 몸가짐을 뜻한다. 전통적인 분 제목은 여래의 겉으로 드러난 움직임을 말하지만, 본문은 여래를 그 움직임에 한정하여 이해하지 말라고 한다.

2. <a name="c29-note-02"></a>역사적 인물인 부처가 실제로 이동하거나 앉고 눕지 않았다는 말이 아니다. 조건에 따라 나타나는 몸의 동작을 여래의 궁극적인 본질로 붙잡을 수 없다는 뜻이다.

3. <a name="c29-note-03"></a>`如來`에 해당하는 산스크리트 `tathāgata`는 여러 방식으로 풀이되어 왔다. 이 대목은 그 말을 `어디에서도 오지 않고 어디로도 가지 않은 이`라는 역설로 설명한다.

4. <a name="c29-note-04"></a>산스크리트본에는 구마라집본의 `臥`, 곧 눕는다는 말에 해당하는 표현과 더불어 서 있다는 동작도 나온다. 어느 자세를 취하든 여래를 공간 속에서 오고 가는 고정된 존재로 규정할 수 없다는 중심 뜻은 같다.

## <a name="source"></a>한문과 현토 독음

<a name="source-c29-001"></a>**「須菩提！若有人言：『如來若來若去、若坐若臥。』**\
“수보리야！약유인언호되：‘여래가 약래약거、약좌약와라。’하면，

<a name="source-c29-002"></a>**是人不解我所說義。何以故？**\
시인은 불해아소설의니라。하이고오？

<a name="source-c29-003"></a>**如來者，無所從來，亦無所去，故名如來。」**\
여래자는 무소종래하며，역무소거할새，고명여래니라。”
