## <a name="term-001"></a>용어 기록 1

**한문과 위치**

`金剛般若波羅蜜經`, 제13분

**산스크리트 대응·관련어**

표제 `Vajracchedikā`, `prajñāpāramitā`; S §13의 문답에는 `prajñāpāramitā`만 있음

**현재 표현과 판단**

본문은 C를 따라 `금강 같은 지혜의 완성`. 기존 `모든 집착을 끊는`은 원문 제목에 없는 목적어이므로 본문에서 덜었다. `Vajracchedikā`의 끊음과 금강의 관계는 주석의 해석 문제로 구별한다.

## <a name="term-002"></a>용어 기록 2

**한문과 위치**

`般若波羅蜜`

**산스크리트 대응·관련어**

`prajñāpāramitā`

**현재 표현과 판단**

지혜의 완성. `prajñā`는 통찰의 지혜, `pāramitā`는 완성·완전성으로 이해했다. 피안에 이름이라는 전통적 설명도 가능하지만 유일한 어원 분석으로 확정하지 않는다.

**현재 표현과 판단**

세존. 문법 형태가 달라져도 같은 존칭이다.

## <a name="term-006"></a>용어 기록 6

**한문과 위치**

`菩薩摩訶薩`

**산스크리트 대응·관련어**

`bodhisattva mahāsattva`

**현재 표현과 판단**

보살 마하살. `보살의 길에 나선 이`는 관련 표현 `bodhisattvayānasaṃprasthita`를 풀어 옮긴 경우다.

## <a name="term-007"></a>용어 기록 7

**한문과 위치**

`阿耨多羅三藐三菩提`

**산스크리트 대응·관련어**

`anuttarā samyaksaṃbodhi`

**현재 표현과 판단**

가장 높고 바른 깨달음. 원어의 `위없는`, `바른`, `완전한 깨달음`이라는 범위를 번역 주에서 보완한다. 반야심경의 조금 더 긴 표현과 독송 문체를 완전히 통일할지는 추후 검토한다.

## <a name="term-008"></a>용어 기록 8

**위치·한문**

제3·6·14분의 나·사람·중생·생명에 관한 `相`

**산스크리트**

`saṃjñā`

**현재 표현과 의미 범위**

관념. 대상을 알아보고 표상하는 인식 작용이며 단순히 겉모습만을 말하지 않는다. 이 문맥에서는 나·사람·중생·생명을 규정하여 붙잡는 관념을 경계한다.

## <a name="term-009"></a>용어 기록 9

**위치·한문**

제4분 `不住於相`

**산스크리트**

`nimittasaṃjñā`

**현재 표현과 의미 범위**

상에 머무르지 않음. `nimitta`의 표지·표상과 `saṃjñā`의 인식·관념이 결합한다. 단순한 외형의 부정으로 읽지 않는다.

## <a name="term-010"></a>용어 기록 10

**위치·한문**

제5분 `身相`, 제20·26분 `具足諸相·三十二相`

**산스크리트**

`lakṣaṇa`, `lakṣaṇasaṃpad`

**현재 표현과 의미 범위**

몸의 특징·모습, 특징을 온전히 갖춤. 인식 주체의 관념과 대상을 가리키는 특징을 구별한다.

## <a name="term-011"></a>용어 기록 11

**위치·한문**

제14분 `實相`

**산스크리트**

`bhūtasaṃjñā`

**현재 표현과 의미 범위**

참됨에 대한 관념. 이 어구의 산스크리트를 근거로 선택했다. 다른 경론의 `實相`까지 언제나 이 원어에 대응한다고 일반화하지 않는다.

## <a name="term-012"></a>용어 기록 12

**위치·한문**

제30분 `一合相`

**산스크리트**

`piṇḍagrāha`

**현재 표현과 의미 범위**

하나의 덩어리로 붙잡음. `piṇḍa`는 덩어리, `grāha`는 붙잡음이다. 뒤의 `agrāha`와 어근을 맞추어 부정·명명의 반복을 살렸다.

## <a name="term-013"></a>용어 기록 13

**위치·한문**

제31분 `我見` 등

**산스크리트**

`ātma-dṛṣṭi` 등

**현재 표현과 의미 범위**

나라는 견해. 여기서는 `相/saṃjñā`와 달리 `見/dṛṣṭi`가 사용되므로 관념과 견해를 구별한다.

## <a name="term-016"></a>용어 기록 16

**C의 표현**

`眾生`

**의미상 대응하는 S의 어근**

**현재 번역과 주의점**

## <a name="term-017"></a>용어 기록 17

**현재 번역과 주의점**

생명. 2026-11-01에 종전 `영속하는 생명`의 수식어를 덜었다. 지속하는 생명 주체로 붙잡는다는 해석은 주에 두고, 원문에 없는 `영속하는`으로 관념·부정의 범위를 미리 좁히지 않는다.

`cittadhārā`

**현재 표현과 판단**

갖가지 마음의 흐름. S는 마음이 이어지는 흐름을 명시하고, C는 갖가지 마음으로 표현한다.

## <a name="term-032"></a>용어 기록 32

**한문과 위치**

`受持`

**산스크리트 대응·관련어**

`udgrahaṇa` 계열, `dhārayati` 계열

**현재 표현과 판단**

받아 지님. 배우고 받아들임, 기억하여 지님을 포함한다. 단어 자체가 모든 일상 수행을 직접 명령한다고 부풀리지는 않는다.

## <a name="term-033"></a>용어 기록 33

**한문과 위치**

`讀誦`과 관련 열거

**산스크리트 대응·관련어**

`vācayati`, `paryavāpnoti` 계열

**현재 표현과 판단**

읽고 외움·익힘. S의 항목 수와 C의 압축 표현을 언제나 일대일로 놓지 않는다.

## <a name="term-034"></a>용어 기록 34

**한문과 위치**

`四句偈`

**산스크리트 대응·관련어**

`catuṣpādikā gāthā`

**현재 표현과 판단**

네 구절로 된 게송. 반드시 제32분의 마지막 게송만을 지칭한다고 확정하지 않는다.

## <a name="term-035"></a>용어 기록 35

**한문과 위치**

제3분 `無餘涅槃`

**산스크리트 대응·관련어**

`anupadhiśeṣa-nirvāṇadhātu`

**현재 표현과 판단**

남김 없는 열반. 더 엄밀한 열반 분류와 `upadhi`의 해설은 별도 논서 근거를 더 확인할 과제로 둔다.

## <a name="term-036"></a>용어 기록 36

**한문과 위치**

제29분 `如來`의 설명

**산스크리트 대응·관련어**

`na kvacid gata`, `na kutaścid āgata`

**현재 표현과 판단**

어디에서도 오지 않고 어디로도 가지 않음. 조건에 따라 나타나는 동작을 부정한다기보다 여래를 동작으로 확정하지 않는 문맥으로 읽었다.
