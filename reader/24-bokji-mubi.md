# <a name="top"></a>제24분 복지무비분(福智無比分) — 복덕과 지혜는 견줄 수 없음

## <a name="translation"></a>한글 번역

세존께서 말씀하셨다.

“수보리여, 어떤 사람이 삼천대천세계에 있는 모든 수미산만큼 일곱 가지 보물을 쌓아 여래들께 베푼다고 하자.

또 어떤 사람이 이 지혜의 완성에 관한 경전에서 네 구절로 된 게송 하나만이라도 받아 지니고 읽고 외우며 다른 이에게 설명한다고 하자.

앞의 복덕은 뒤의 복덕에 견주면 백분의 일에도 미치지 못하고, 백천만억분의 일에도 미치지 못한다. 어떠한 계산이나 비유로도 그 차이를 다 나타낼 수 없다.”

## <a name="notes"></a>번역 주

1. <a name="c24-note-01"></a>`須彌山王`은 불교의 우주관에서 한 세계의 중심에 솟은 가장 거대한 산을 가리킨다. 그 수미산이 삼천대천세계마다 있는 만큼 보석 무더기를 쌓는다는 극단적인 비유다.

2. <a name="c24-note-02"></a>산스크리트본은 보물을 `tathāgatebhyo 'rhadbhyaḥ samyaksaṃbuddhebhyo`에게 베푼다고 명시한다. 이는 세 부류를 나열한 말이 아니라 `아라한이며 바르게 완전히 깨달은 여래들`이라는 같은 이들을 꾸미는 호칭들이다. 구마라집본에는 받는 이가 없으며, 앞선 보시 대목과 일관되게 본문에는 `여래들께`로 보완했다.

3. <a name="c24-note-03"></a>`受持·讀誦`은 가르침을 받아 간직하고, 글을 읽고, 기억하여 소리 내어 외우는 일을 아울러 가리킨다.

4. <a name="c24-note-04"></a>물질 보시를 무가치하다고 하는 대목이 아니다. 아무리 큰 재물도 유한하지만, 집착에서 벗어나게 하는 지혜가 일으키는 변화는 수량으로 견주기 어렵다는 뜻이다.

## <a name="source"></a>한문과 현토 독음

<a name="source-c24-001"></a>**「須菩提！若三千大千世界中所有諸須彌山王，如是等七寶聚，有人持用布施；**\
“수보리야！약 삼천대천세계중 소유제수미산왕과 여시등칠보취를，유인이 지용보시하고；

<a name="source-c24-002"></a>**若人以此般若波羅蜜經，乃至四句偈等，受持、讀誦，為他人說，**\
약인이 이차반야바라밀경으로，내지사구게등을 수지、독송하여，위타인설하면，

<a name="source-c24-003"></a>**於前福德百分不及一，百千萬億分，乃至算數譬喻所不能及。」**\
어전복덕은 백분불급일이며，백천만억분과 내지산수비유로도 소불능급이니라。”
