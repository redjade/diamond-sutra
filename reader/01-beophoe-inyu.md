# <a name="top"></a>제1분 법회인유분(法會因由分) — 법회가 열린 까닭

## <a name="translation"></a>한글 번역

나는 이와 같이 들었다.

어느 때 부처님께서는 사위국의 제타 숲, 급고독의 동산에 큰 비구 대중 천이백오십 명과 함께 머무셨다.

공양할 때가 되자 세존께서는 가사를 입고 발우를 드신 채 큰 성읍인 사위성으로 탁발하러 들어가셨다. 성 안에서 차례로 음식을 받아 본래 머무시던 곳으로 돌아오셨다. 공양을 마치신 뒤에는 가사와 발우를 거두고 발을 씻은 다음, 자리를 펴고 앉으셨다.

## <a name="notes"></a>번역 주

1. <a name="c01-note-01"></a>`祇樹給孤獨園`에 대응하는 산스크리트는 `jetavana`와 `Anāthapiṇḍada`의 동산을 함께 든다. 본문은 두 이름을 드러내 `제타 숲, 급고독의 동산`으로 옮겼다. `기원정사`는 익숙한 별칭이지만 그 말 하나로 지명과 동산 이름을 대체하지 않았다.

2. <a name="c01-note-02"></a>구마라집 T235는 비구 대중을 1,250명으로 적는다. 대조한 Vaidya 전자본은 `trayodaśabhir bhikṣuśataiḥ`, 곧 비구 1,300명이며 여러 보살 마하살도 함께 있었다고 한다. 한글 본문의 인원과 청중 범위는 T235를 따른다.

3. <a name="c01-note-03"></a>T235의 `食時`에는 아침이라는 말이 없고, Vaidya본은 오전을 명시한다. 본문은 `공양할 때`로 두었다. `著衣`의 옷은 수행자의 가사이며, `乞食`은 탁발하여 음식을 구하는 일이다.

4. <a name="c01-note-04"></a>`敷座而坐`는 자리를 펴고 앉는 동작이다. 산스크리트는 이미 마련된 자리에 앉는 것으로 표현한다. 본문은 T235의 동작을 살렸다.

5. <a name="c01-note-05"></a>Vaidya본에는 앉을 때 가부좌하고 몸을 곧게 세워 마음챙김을 앞에 확립하는 모습과, 비구들이 부처님 발에 예배하고 세 번 오른쪽으로 돈 뒤 한쪽에 앉는 장면이 더 있다. T235에는 이 구절들이 없다. 이 차이만으로 두 판본의 역사적 선후 관계를 확정하지 않는다.

6. <a name="c01-note-06"></a>`如是我聞`(산스크리트 `evaṃ mayā śrutam`)은 `나는 이와 같이 들었다`로 유지한다. `mayā`는 일인칭 대명사의 도구격으로, 들은 이를 밝힌다. `śrutam`은 들음을 나타내는 과거 수동분사이지만, `그와 같이 들렸다`로만 옮기면 원문에 명시된 들은 이가 빠진다. 팔리 정형구 `evaṁ me sutaṁ`(DN 1, 1.1.1)도 일인칭 `me`를 포함한다. 이 대명사들은 자아를 뜻하는 `ātman/attā`와 구별한다. SN 1.25, 2.3–2.6과 4.1–5.3에서는 아라한도 세상의 명칭을 알아 일상적인 말로 `내가 말한다`·`사람들이 나에게 말한다`라고 할 수 있다고 설명한다. 따라서 일인칭 자체를 삭제하는 것으로 무아를 표현하지 않는다. 이 분의 `나`는 들은 내용을 전하는 화자를 가리키며, 영원한 자아를 세운다는 해석을 덧붙이지 않는다. `이와 같이 들었다`는 한국어의 주어 생략으로 가능하지만, 여기서는 C의 `我`와 S의 `mayā`를 드러내는 표현을 채택했다. 원문에 없는 `연기하여`도 본문에 넣지 않는다. 이 팔리 경들은 금강경의 팔리 원전이 아니라 평행 가르침·정형구 참고이며, 고정 커밋과 확인 구절은 [근거 기록](../SOURCES.md)에 적었다.

## <a name="source"></a>한문과 현토 독음

<a name="source-c01-001"></a>**如是我聞：**\
여시아문하니：

<a name="source-c01-002"></a>**一時，佛在舍衛國祇樹給孤獨園，與大比丘眾千二百五十人俱。**\
일시에, 불이 사위국 기수급고독원에 재하시며, 여 대비구중 천이백오십인 구하시니라.

<a name="source-c01-003"></a>**爾時，世尊食時，著衣持鉢，入舍衛大城乞食。**\
이시에, 세존이 식시에 착의지발하시고, 사위대성에 입하사 걸식하시니라.

<a name="source-c01-004"></a>**於其城中，次第乞已，還至本處。**\
어기성중에 차제걸이하시고, 환지본처하시니라.

<a name="source-c01-005"></a>**飯食訖，收衣鉢，洗足已，敷座而坐。**\
반사흘하시고, 수의발하시며, 세족이하시고, 부좌이좌하시니라.
