# <a name="top"></a>제2분 선현기청분(善現起請分) — 수보리가 가르침을 청하다

## <a name="translation"></a>한글 번역

그때 장로 수보리가 대중 가운데에서 일어났다. 오른쪽 어깨를 드러내고 오른쪽 무릎을 땅에 댄 뒤, 세존을 향해 두 손을 모아 공경히 여쭈었다.

“참으로 놀랍습니다, 세존이시여. 여래께서는 보살들을 지극히 보살펴 주시고, 보살들에게 가르침을 잘 당부해 주십니다.

세존이시여, 가장 높고 바른 깨달음을 향한 마음을 낸 선한 남자와 선한 여자는 어떻게 머물러야 하며, 어떻게 수행해야 하며, 그 마음을 어떻게 다스려야 합니까?”

세존께서 말씀하셨다.

“훌륭하다, 훌륭하다, 수보리여. 네 말과 같다. 여래는 보살들을 지극히 보살피고, 보살들에게 가르침을 잘 당부한다.

그러니 이제 자세히 듣고 마음에 깊이 새겨라. 보살의 길에 나선 이는 어떻게 머물러야 하고, 어떻게 수행해야 하며, 그 마음을 어떻게 다스려야 하는지 내가 말하겠다.”

수보리가 아뢰었다.

“그렇게 하겠습니다, 세존이시여. 기쁜 마음으로 듣고자 합니다.”

## <a name="source"></a>한문과 현토 독음

<a name="source-c02-001"></a>**時，長老須菩提在大眾中即從座起，偏袒右肩，右膝著地，合掌恭敬而白佛言：**\
시에, 장로수보리가 재대중중하여 즉종좌기하고, 편단우견하며, 우슬착지하고, 합장공경이백불언하되：

<a name="source-c02-002"></a>**「希有！世尊！如來善護念諸菩薩，善付囑諸菩薩。**\
「희유하십니다！ 세존이시여！ 여래께서 선호념제보살하시며, 선부촉제보살하십니다.

<a name="source-c02-003"></a>**世尊！善男子、善女人，發阿耨多羅三藐三菩提心，應云何住？云何降伏其心？」**\
세존이시여！ 선남자、선여인이 발아뇩다라삼먁삼보리심하면, 응운하주하며？ 운하항복기심하리이까？」

<a name="source-c02-004"></a>**佛言：「善哉，善哉！須菩提！如汝所說：**\
불언하시되：「선재라, 선재라！ 수보리여！ 여여소설하니：

<a name="source-c02-005"></a>**『如來善護念諸菩薩，善付囑諸菩薩。』**\
『여래께서 선호념제보살하시며, 선부촉제보살하신다。』

<a name="source-c02-006"></a>**汝今諦聽，當為汝說。**\
여금제청하라, 당위여설하리라.

<a name="source-c02-007"></a>**善男子、善女人，發阿耨多羅三藐三菩提心，應如是住，如是降伏其心。」**\
선남자、선여인이 발아뇩다라삼먁삼보리심하면, 응여시주하며, 여시항복기심하라。」

<a name="source-c02-008"></a>**「唯然。世尊！願樂欲聞。」**\
「유연하옵니다。 세존이시여！ 원요욕문하옵니다。」
