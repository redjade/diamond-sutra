# <a name="top"></a>제24분 복지무비분(福智無比分) — 복덕과 지혜는 견줄 수 없음 · 주석

## <a name="c24-note-01"></a>번역 주 1

`須彌山王`은 불교의 우주관에서 한 세계의 중심에 솟은 가장 거대한 산을 가리킨다. 그 수미산이 삼천대천세계마다 있는 만큼 보석 무더기를 쌓는다는 극단적인 비유다.

[해당 분의 번역으로](../24-bokji-mubi.md#translation)

## <a name="c24-note-02"></a>번역 주 2

산스크리트본은 보물을 `tathāgatebhyo 'rhadbhyaḥ samyaksaṃbuddhebhyo`에게 베푼다고 명시한다. 이는 세 부류를 나열한 말이 아니라 `아라한이며 바르게 완전히 깨달은 여래들`이라는 같은 이들을 꾸미는 호칭들이다. 구마라집본에는 받는 이가 없으며, 앞선 보시 대목과 일관되게 본문에는 `여래들께`로 보완했다.

[해당 분의 번역으로](../24-bokji-mubi.md#translation)

## <a name="c24-note-03"></a>번역 주 3

`受持·讀誦`은 가르침을 받아 간직하고, 글을 읽고, 기억하여 소리 내어 외우는 일을 아울러 가리킨다.

[해당 분의 번역으로](../24-bokji-mubi.md#translation)

## <a name="c24-note-04"></a>번역 주 4

물질 보시를 무가치하다고 하는 대목이 아니다. 아무리 큰 재물도 유한하지만, 집착에서 벗어나게 하는 지혜가 일으키는 변화는 수량으로 견주기 어렵다는 뜻이다.

[해당 분의 번역으로](../24-bokji-mubi.md#translation)
