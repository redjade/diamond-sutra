# <a name="top"></a>제16분 능정업장분(能淨業障分) — 업의 장애를 맑히다 · 주석

## <a name="c16-note-01"></a>번역 주 1

산스크리트본은 경전을 `받아 지니고, 읽고, 익혀 통달하며, 이치에 맞게 마음에 새기고, 다른 이에게 자세히 설명하는` 사람을 말한다. 구마라집본에는 `받아 지니고 읽고 외운다`는 표현이 있으며, 본문에는 행위의 범위를 분명히 하려고 산스크리트본의 내용을 보완했다. 공덕을 비교하는 미래 시점도 구마라집본에는 `후말세`, 산스크리트본에는 `마지막 오백 년에 바른 가르침이 사라져 갈 때`라는 표현이 있으므로 본문의 `가르침이 쇠퇴하는 마지막 시대`는 산스크리트본을 함께 반영한 표현이다.

[해당 분의 번역으로](../16-neungjeong-eopjang.md#translation)

## <a name="c16-note-02"></a>번역 주 2

`罪業`은 신이 내리는 벌이 아니라 의도적인 행위가 남기는 좋지 않은 결과를 뜻한다. `惡道`는 그러한 업으로 겪게 되는 극심한 괴로움의 삶을 가리킨다.

[해당 분의 번역으로](../16-neungjeong-eopjang.md#translation)

## <a name="c16-note-03"></a>번역 주 3

이 문장은 누군가 받는 모욕이나 부당한 대우를 과거의 잘못 탓으로 단정하거나 정당화하라는 가르침이 아니다. 경전을 지녀도 고난이 사라진다고 보장할 수 없지만, 고난이 수행과 깨달음의 길을 반드시 무너뜨리는 것은 아니라는 경전 내부의 업 해석이다.

[해당 분의 번역으로](../16-neungjeong-eopjang.md#translation)

## <a name="c16-note-04"></a>번역 주 4

`八百四千萬億那由他`는 정확한 통계가 아니라 셀 수 없이 큰 수를 나타낸다. 산스크리트 Vaidya본은 `팔십사 코티·니유타·십만`의 부처라고 하여 수의 표현에 차이가 있다.

[해당 분의 번역으로](../16-neungjeong-eopjang.md#translation)

## <a name="c16-note-05"></a>번역 주 5

산스크리트본은 연등불 이전의 그 부처들을 섬기면서 `기쁘게 해 드렸고 불쾌하게 하지 않았다`고 표현한다. 한역의 `한 분도 헛되이 지나치지 않았다`와 강조점이 조금 다르다.

[해당 분의 번역으로](../16-neungjeong-eopjang.md#translation)

## <a name="c16-note-06"></a>번역 주 6

공덕의 비교에서 구마라집본은 `백분의 일`과 `천만억분`을 들고 계산과 비유로도 미치지 못한다고 한다. 본문은 구마라집본의 수열을 따랐다. 산스크리트본은 천분의 일, 백천분의 일, 코티분의 일 등을 더 길게 열거하므로 두 수열을 한 문장으로 합치지 않고 판본 차이로 남긴다.

[해당 분의 번역으로](../16-neungjeong-eopjang.md#translation)

## <a name="c16-note-07"></a>번역 주 7

`果報`에 해당하는 산스크리트 `vipāka`는 행위와 수행이 무르익어 나타나는 결과를 뜻한다. 불가사의하다는 말은 인과가 없다는 뜻이 아니라, 그 크기와 전개를 단순한 셈으로 다 나타낼 수 없다는 뜻이다.

[해당 분의 번역으로](../16-neungjeong-eopjang.md#translation)
