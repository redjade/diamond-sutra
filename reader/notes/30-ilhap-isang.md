# <a name="top"></a>제30분 일합이상분(一合理相分) — 하나로 합쳐졌다는 관념 · 주석

## <a name="c30-note-01"></a>번역 주 1

티끌과 세계는 서로 반대되는 두 실체가 아니다. 세계는 수많은 조건과 부분을 의지해 세계라 불리고, 티끌 또한 더는 나눌 수 없는 독립된 실체로 확정되지 않는다.

[해당 분의 번역으로](../30-ilhap-isang.md#translation)

## <a name="c30-note-02"></a>번역 주 2

산스크리트본의 비유는 구마라집본보다 규모가 크다. 삼천대천세계에 있는 티끌 수만큼의 세계를 다시 미세한 원자로 만들 경우를 묻지만, 구마라집본은 하나의 삼천대천세계를 티끌로 부순다고 간결하게 옮긴다.

[해당 분의 번역으로](../30-ilhap-isang.md#translation)

## <a name="c30-note-03"></a>번역 주 3

`一合相`은 여러 요소가 모여 하나의 단단한 전체를 이룬다는 관념이다. 산스크리트 `piṇḍagrāha`는 `한 덩어리로 붙잡음`이라는 뜻이고, 이어서 그것을 `agrāha`, 곧 붙잡음이 아니라고 부정한다. 이 어근의 반복을 살리기 위해 본문을 `하나의 덩어리로 붙잡음`으로 고쳤다. 이것을 독립된 하나의 실체로 취할 수 없다는 뜻은 주석에서만 풀이했다.

[해당 분의 번역으로](../30-ilhap-isang.md#translation)

## <a name="c30-note-04"></a>번역 주 4

`不可說`은 세계에 관해 아무 말도 해서는 안 된다는 뜻이 아니다. `세계`나 `하나`라는 이름은 일상에서 쓸 수 있지만, 그 이름에 대응하는 독립된 실체를 말로 나타낼 수 없다는 뜻이다. 산스크리트본은 이를 `avyavahāra`와 `anabhilāpya`라고 하고, 다시 `법도 아니고 법 아닌 것도 아니다`라고 덧붙이지만 이 마지막 문구는 구마라집본에 없다.

[해당 분의 번역으로](../30-ilhap-isang.md#translation)

## <a name="c30-note-05"></a>번역 주 5

마지막의 `貪著其事`는 범부가 일상의 사물을 경험한다는 사실을 탓하지 않는다. 조건의 모임을 독립된 실재로 여기고 거기에 매달리는 것을 가리킨다.

[해당 분의 번역으로](../30-ilhap-isang.md#translation)
