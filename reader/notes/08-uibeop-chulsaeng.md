# <a name="top"></a>제8분 의법출생분(依法出生分) — 모든 깨달음이 이 가르침에서 나오다 · 주석

## <a name="c08-note-01"></a>번역 주 1

`三千大千世界`는 작은 세계 삼천 개를 뜻하지 않는다. 하나의 세계가 천 개 모인 단위, 그것이 다시 천 개 모인 단위, 그리고 그것이 다시 천 개 모인 광대한 우주를 가리키는 불교의 표현이다. 독송 본문에서는 전통 용어를 유지했다.

[해당 분의 번역으로](../08-uibeop-chulsaeng.md#translation)

## <a name="c08-note-02"></a>번역 주 2

산스크리트본의 `여래·아라한·바르게 깨달은 이들`은 같은 부처들을 가리키는 존칭의 나열로 읽는다. 서로 다른 수혜 집단을 추가한 `여래와 성자들`을 `여래들`로 고쳤다. 선한 남녀와 받는 이는 Vaidya본에 명시되어 있으나 T235는 `어떤 사람`의 보시라고만 하므로, 이 부분의 한글은 산스크리트를 보완한 것이다.

[해당 분의 번역으로](../08-uibeop-chulsaeng.md#translation)

## <a name="c08-note-03"></a>번역 주 3

`福德即非福德性`은 선행의 결과를 부정하는 말이 아니다. 복덕을 독립적으로 존재하며 소유할 수 있는 실체로 여기지 않는다는 뜻이다. 산스크리트본은 이를 `복덕의 무더기는 무더기가 아니다`라는 금강경 특유의 표현으로 말한다.

[해당 분의 번역으로](../08-uibeop-chulsaeng.md#translation)

## <a name="c08-note-04"></a>번역 주 4

`四句偈`는 금강경 끝부분의 특정 게송만을 가리킨다고 단정하기 어렵다. 산스크리트 `catuṣpādikā gāthā`는 네 구절로 이루어진 게송 한 수를 뜻하므로 `네 구절로 된 게송 하나`로 옮겼다.

[해당 분의 번역으로](../08-uibeop-chulsaeng.md#translation)

## <a name="c08-note-05"></a>번역 주 5

`佛法`은 부처의 가르침뿐 아니라 부처를 이루는 법·특성을 가리킬 여지도 있어 `부처의 법`으로 열어 두었다. T235의 마지막 문장은 `即非佛法`에서 끝난다. Vaidya본의 `그러므로 부처의 법이라 불린다`는 문구는 한글 본문에서도 덜어 내고 여기에서 판본 차이로 밝힌다.

[해당 분의 번역으로](../08-uibeop-chulsaeng.md#translation)

## <a name="c08-note-06"></a>번역 주 6

복덕에 관한 답변은 T235의 `福德性`과 `說福德多`를 살려 옮겼다. `본성`을 자성·실체로 이해할 수 있으나 그런 해석을 본문의 직접 수식어로 미리 확정하지 않았다. 산스크리트의 무더기와 명명 구조는 위 주석에 남겼다. 비교문의 `자세히`, `헤아릴 수 없을`은 Vaidya본을 반영한 보완이다.

[해당 분의 번역으로](../08-uibeop-chulsaeng.md#translation)
