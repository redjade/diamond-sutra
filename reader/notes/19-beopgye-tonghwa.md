# <a name="top"></a>제19분 법계통화분(法界通化分) — 복덕은 온 법계에 통하다 · 주석

## <a name="c19-note-01"></a>번역 주 1

산스크리트본은 보물을 `tathāgatebhyo 'rhadbhyaḥ samyaksaṃbuddhebhyo`에게 베푼다고 명시한다. 세 표현은 서로 다른 세 집단이 아니라 같은 이들을 꾸미는 복수 여격, 곧 `아라한이며 바르게 완전히 깨달은 여래들께`라는 뜻이다. 구마라집본에는 받는 이가 없으며, 제8분과 마찬가지로 본문에는 `여래들께`로 보완했다.

[해당 분의 번역으로](../19-beopgye-tonghwa.md#translation)

## <a name="c19-note-02"></a>번역 주 2

`福德有實`은 선행의 결과가 실제로 없다는 물음이 아니다. 복덕을 독립하여 영원히 존재하는 물건처럼 붙잡을 수 있는지를 묻는다.

[해당 분의 번역으로](../19-beopgye-tonghwa.md#translation)

## <a name="c19-note-03"></a>번역 주 3

산스크리트본은 `복덕의 무더기`가 실재한다면 여래가 그것을 복덕의 무더기라고 말하지 않았을 것이라고 표현한다. 이름은 유용하지만 그 이름에 해당하는 고정된 실체가 따로 있다는 생각은 경계하는 금강경의 어법이다.

[해당 분의 번역으로](../19-beopgye-tonghwa.md#translation)

## <a name="c19-note-04"></a>번역 주 4

2026-10-30 교정: `若福德有實`과 `以福德無故`를 `고정된 실체`로 풀던 본문을 원문의 `有實`·`無`에 맞춰 직접 옮겼다. S도 `sacet punaḥ subhūte puṇyaskandho 'bhaviṣyat`, 곧 `복덕의 무더기가 있었다면`이라고 한다. 이것이 선행의 결과를 부정하지 않는다는 뜻은 주석 2에 둔다.

[해당 분의 번역으로](../19-beopgye-tonghwa.md#translation)
