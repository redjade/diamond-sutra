# <a name="top"></a>제20분 이색이상분(離色離相分) — 형색과 특징을 떠나다 · 주석

## <a name="c20-note-01"></a>번역 주 1

`具足色身`에 해당하는 산스크리트 `rūpakāyapariniṣpatti`는 형색을 지닌 몸의 완전한 성취를 뜻한다. 부처의 몸을 부정하는 것이 아니라, 눈에 보이는 완전한 몸을 곧 여래 자체라고 여기는 견해를 경계한다.

[해당 분의 번역으로](../20-isaek-isang.md#translation)

## <a name="c20-note-02"></a>번역 주 2

`具足諸相`에 해당하는 `lakṣaṇasaṃpad`는 위대한 사람의 뛰어난 신체적 특징을 온전히 갖춘 상태를 가리킨다. 제5분의 `身相`과 마찬가지로, 특징은 여래를 가리키는 표지가 될 수 있어도 여래를 고정하는 실체는 아니다.

[해당 분의 번역으로](../20-isaek-isang.md#translation)

## <a name="c20-note-03"></a>번역 주 3

두 문단은 몸 전체의 완전함과 낱낱의 훌륭한 특징을 나누어 묻는다. 어느 쪽도 여래를 외형과 동일시할 근거가 될 수 없다는 점에서는 뜻이 같다.

[해당 분의 번역으로](../20-isaek-isang.md#translation)

## <a name="c20-note-04"></a>번역 주 4

2026-10-30 교정: 두 대답의 `고정된`을 덜고 `即非具足色身`과 `即非具足`을 직접 부정으로 옮겼다. 둘째 대답에서 C는 `諸相具足`을 `即非具足`, 곧 `갖춤이 아니다`로 받는다.

[해당 분의 번역으로](../20-isaek-isang.md#translation)
