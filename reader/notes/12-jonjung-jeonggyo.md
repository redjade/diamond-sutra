# <a name="top"></a>제12분 존중정교분(尊重正教分) — 바른 가르침을 존중하다 · 주석

## <a name="c12-note-01"></a>번역 주 1

`天、人、阿修羅`는 불교의 세계관에서 신적 존재와 인간과 아수라를 아우르는 표현이다. 곧 모든 세계가 이 가르침을 존중해야 한다는 뜻이다.

[해당 분의 번역으로](../12-jonjung-jeonggyo.md#translation)

## <a name="c12-note-02"></a>번역 주 2

`塔廟`에 해당하는 산스크리트 `caitya`는 부처의 유물이나 기억을 모시고 예배하는 성소를 가리킨다. 경전을 말하는 자리 자체가 그러한 성소가 된다는 비유이다.

[해당 분의 번역으로](../12-jonjung-jeonggyo.md#translation)

## <a name="c12-note-03"></a>번역 주 3

산스크리트본은 경전 전체를 `받아 지니고, 읽고, 익혀 통달하며, 다른 이에게 자세히 설명하는` 일까지 열거한다. 구마라집본은 이를 `받아 지니고 읽고 외운다`고 간결하게 옮겼다.

[해당 분의 번역으로](../12-jonjung-jeonggyo.md#translation)

## <a name="c12-note-04"></a>번역 주 4

마지막의 `若尊重弟子`는 문법과 판본에 따라 해석이 갈린다. 한문만 따르면 `존중받는 제자가 있는 곳`으로 읽을 수 있다. 산스크리트 Vaidya본은 그곳에 `스승이 머물거나, 스승의 자리에 있는 지혜로운 이가 있다`고 하므로 본문은 이 뜻을 따랐다.

[해당 분의 번역으로](../12-jonjung-jeonggyo.md#translation)

## <a name="c12-note-05"></a>번역 주 5

경전이 있는 물리적 장소를 신성시하는 데만 뜻이 있는 것은 아니다. 지혜의 가르침이 실제로 읽히고 이해되어 전해지는 자리가 부처를 만나는 자리와 다르지 않음을 강조한다.

[해당 분의 번역으로](../12-jonjung-jeonggyo.md#translation)

## <a name="c12-note-06"></a>번역 주 6

2026-10-30 교정: 본문의 `부처를 대신할 만큼 지혜로운 스승`은 S의 `vijñagurusthānīyaḥ`(스승의 자리에 있는 지혜로운 이)를 넘어서는 표현이어서 번역 주 4와 같은 뜻으로 고쳤다.

[해당 분의 번역으로](../12-jonjung-jeonggyo.md#translation)
