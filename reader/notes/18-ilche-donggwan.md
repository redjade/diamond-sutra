# <a name="top"></a>제18분 일체동관분(一體同觀分) — 모든 중생의 마음을 두루 보다 · 주석

## <a name="c18-note-01"></a>번역 주 1

`肉眼·天眼·慧眼·法眼·佛眼`은 전통적으로 오안(五眼)이라 부른다. 육안은 일상의 눈, 천안은 보통의 시야를 넘어 보는 눈, 혜안은 공성을 통찰하는 지혜, 법안은 가르침과 존재의 차이를 분명히 보는 눈, 불안은 이 모든 것을 원만히 아는 부처의 눈을 가리킨다.

[해당 분의 번역으로](../18-ilche-donggwan.md#translation)

## <a name="c18-note-02"></a>번역 주 2

한역의 `若干種心`은 갖가지 마음이라는 뜻이다. 산스크리트본은 이를 `nānābhāvāṃ cittadhārām`, 곧 저마다 다른 양상으로 이어지는 마음의 흐름이라고 표현하므로 그 뜻을 본문에 살렸다.

[해당 분의 번역으로](../18-ilche-donggwan.md#translation)

## <a name="c18-note-03"></a>번역 주 3

`諸心皆為非心，是名為心`은 생각이나 마음의 작용이 전혀 없다는 말이 아니다. 마음은 순간마다 조건에 따라 일어나고 사라지므로, 하나의 변하지 않는 실체로 붙잡을 수 없다는 뜻이다.

[해당 분의 번역으로](../18-ilche-donggwan.md#translation)

## <a name="c18-note-04"></a>번역 주 4

`不可得`은 과거·현재·미래의 마음을 경험할 수 없다는 뜻이 아니라, 어느 때의 마음도 고정된 실체로 찾아내어 소유할 수 없다는 뜻이다. 산스크리트본은 과거·미래·현재의 순서로 들지만 의미에는 차이가 없다.

[해당 분의 번역으로](../18-ilche-donggwan.md#translation)
