# <a name="top"></a>제22분 무법가득분(無法可得分) — 얻을 수 있는 법이 없음 · 주석

## <a name="c22-note-01"></a>번역 주 1

`無所得`은 깨달음의 부정이 아니라, 깨달음을 수행하는 내가 새로 소유한 어떤 물건이나 고정된 상태로 여기지 않는다는 뜻이다.

[해당 분의 번역으로](../22-mubeop-gadeuk.md#translation)

## <a name="c22-note-02"></a>번역 주 2

`乃至無有少法可得`에 해당하는 산스크리트는 `원자만큼 작은 법조차 거기에는 존재하지 않으며 얻을 수 없다`고 강조한다.

[해당 분의 번역으로](../22-mubeop-gadeuk.md#translation)

## <a name="c22-note-03"></a>번역 주 3

제7분에서는 여래가 깨달았다고 이름 붙일 고정된 법이 없다고 말했고, 여기서는 그 뜻을 수보리의 질문과 세존의 확인으로 다시 밝힌다.

[해당 분의 번역으로](../22-mubeop-gadeuk.md#translation)

## <a name="c22-note-04"></a>번역 주 4

대화의 순서는 판본마다 다르다. 구마라집본에서는 수보리가 `부처님께서 깨달음을 얻으셨지만 얻은 것이 없습니까`라고 묻고 세존이 긍정한다. 산스크리트본에서는 세존이 먼저 `여래가 깨달은 어떤 법이 있느냐`고 묻고 수보리가 부정한 뒤, 세존이 이를 확인한다. 본문은 한역의 순서를 따랐다.

[해당 분의 번역으로](../22-mubeop-gadeuk.md#translation)
