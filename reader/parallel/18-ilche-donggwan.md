# <a name="top"></a>제18분 일체동관분(一體同觀分) — 모든 중생의 마음을 두루 보다 · 대조

기존 한글 문단과 한문·현토 단위의 수가 다릅니다. 분 전체를 대조하며, 문단과 원문 단위가 일대일로 정렬되었다고 표시하지 않습니다.

## 한글 번역

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 여래에게 육신의 눈이 있느냐?”

수보리가 아뢰었다.

“그렇습니다, 세존이시여. 여래에게 육신의 눈이 있습니다.”

“수보리여, 너는 어떻게 생각하느냐? 여래에게 하늘의 눈이 있느냐?”

“그렇습니다, 세존이시여. 여래에게 하늘의 눈이 있습니다.”

“수보리여, 너는 어떻게 생각하느냐? 여래에게 지혜의 눈이 있느냐?”

“그렇습니다, 세존이시여. 여래에게 지혜의 눈이 있습니다.”

“수보리여, 너는 어떻게 생각하느냐? 여래에게 법을 보는 눈이 있느냐?”

“그렇습니다, 세존이시여. 여래에게 법을 보는 눈이 있습니다.”

“수보리여, 너는 어떻게 생각하느냐? 여래에게 부처의 눈이 있느냐?”

“그렇습니다, 세존이시여. 여래에게 부처의 눈이 있습니다.”

“수보리여, 너는 어떻게 생각하느냐? 갠지스강에 있는 모든 모래를 여래가 모래라고 말한 적이 있느냐?”

“그렇습니다, 세존이시여. 여래께서 그 모래를 말씀하셨습니다.”

“수보리여, 너는 어떻게 생각하느냐? 한 갠지스강의 모래알 수만큼 갠지스강이 있고, 그 모든 강의 모래알 수만큼 부처의 세계가 있다면, 그 세계가 많겠느냐?”

“매우 많습니다, 세존이시여.”

세존께서 수보리에게 말씀하셨다.

“그 모든 세계에 사는 중생들의 갖가지 마음의 흐름을 여래는 모두 안다.

왜 그런가? 여래가 말한 모든 마음의 흐름은 마음의 흐름이 아니다. 그러므로 마음의 흐름이라 부르는 것이다.

왜냐하면 수보리여, 지나간 마음은 붙잡을 수 없고, 지금의 마음은 붙잡을 수 없으며, 아직 오지 않은 마음도 붙잡을 수 없기 때문이다.”

## 한문과 현토 독음

<a name="source-c18-001"></a>**「須菩提！於意云何？如來有肉眼不？」**\
수보리야, 어의운하오. 여래가 유육안부아.

<a name="source-c18-002"></a>**「如是，世尊！如來有肉眼。」**\
여시하니이다, 세존이시여. 여래가 유육안이니이다.

<a name="source-c18-003"></a>**「須菩提！於意云何？如來有天眼不？」**\
수보리야, 어의운하오. 여래가 유천안부아.

<a name="source-c18-004"></a>**「如是，世尊！如來有天眼。」**\
여시하니이다, 세존이시여. 여래가 유천안이니이다.

<a name="source-c18-005"></a>**「須菩提！於意云何？如來有慧眼不？」**\
수보리야, 어의운하오. 여래가 유혜안부아.

<a name="source-c18-006"></a>**「如是，世尊！如來有慧眼。」**\
여시하니이다, 세존이시여. 여래가 유혜안이니이다.

<a name="source-c18-007"></a>**「須菩提！於意云何？如來有法眼不？」**\
수보리야, 어의운하오. 여래가 유법안부아.

<a name="source-c18-008"></a>**「如是，世尊！如來有法眼。」**\
여시하니이다, 세존이시여. 여래가 유법안이니이다.

<a name="source-c18-009"></a>**「須菩提！於意云何？如來有佛眼不？」**\
수보리야, 어의운하오. 여래가 유불안부아.

<a name="source-c18-010"></a>**「如是，世尊！如來有佛眼。」**\
여시하니이다, 세존이시여. 여래가 유불안이니이다.

<a name="source-c18-011"></a>**「須菩提！於意云何？恒河中所有沙，佛說是沙不？」**\
수보리야, 어의운하오. 항하중소유사를 불이 설시사부아.

<a name="source-c18-012"></a>**「如是，世尊！如來說是沙。」**\
여시하니이다, 세존이시여. 여래가 설시사니이다.

<a name="source-c18-013"></a>**「須菩提！於意云何？如一恒河中所有沙，有如是等恒河，是諸恒河所有沙數佛世界，如是寧為多不？」**\
수보리야, 어의운하오. 여일항하중소유사에 유여시등항하하고, 시제항하소유사수불세계라면, 여시영위다부아.

<a name="source-c18-014"></a>**「甚多，世尊！」**\
심다니이다, 세존이시여.

<a name="source-c18-015"></a>**佛告須菩提：「爾所國土中，所有眾生若干種心，如來悉知。何以故？如來說諸心皆為非心，是名為心。所以者何？須菩提！過去心不可得，現在心不可得，未來心不可得。」**\
불이 고수보리하시되, 이소국토중에 소유중생의 약간종심을 여래가 실지하느니라. 하이고오. 여래가 설제심은 개위비심이라, 시명위심이니라. 소이자하오. 수보리야, 과거심은 불가득이며 현재심도 불가득이며 미래심도 불가득이니라.
