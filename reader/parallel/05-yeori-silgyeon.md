# <a name="top"></a>제5분 여리실견분(如理實見分) — 이치에 맞게 참으로 보다 · 대조

기존 한글 문단과 한문·현토 단위의 수가 다릅니다. 분 전체를 대조하며, 문단과 원문 단위가 일대일로 정렬되었다고 표시하지 않습니다.

## 한글 번역

“수보리여, 너는 어떻게 생각하느냐? 몸에 드러난 특징으로 여래를 볼 수 있겠느냐?”

“볼 수 없습니다, 세존이시여. 몸에 드러난 특징으로는 여래를 볼 수 없습니다.

왜냐하면 여래께서 몸의 특징이라고 말씀하신 것은 곧 몸의 특징이 아니기 때문입니다.”

세존께서 수보리에게 말씀하셨다.

“무릇 드러난 모든 모습은 허망하다.

모든 모습이
모습 아님을 본다면,
곧 여래를 보리라.”

## 한문과 현토 독음

<a name="source-c05-001"></a>**「須菩提！於意云何？可以身相見如來不？」**\
「수보리여！ 어의운하인가？ 가이신상견여래부아？」

<a name="source-c05-002"></a>**「不也，世尊！不可以身相得見如來。**\
「불야입니다, 세존이시여！ 불가이신상득견여래니이다.

<a name="source-c05-003"></a>**何以故？如來所說身相，即非身相。」**\
하이고인가？ 여래소설신상은, 즉비신상이니이다。」

<a name="source-c05-004"></a>**佛告須菩提：「凡所有相，皆是虛妄。**\
불고수보리하시되：「범소유상은, 개시허망이니라.

<a name="source-c05-005"></a>**若見諸相非相，則見如來。」**\
약견제상비상하면, 즉견여래하리라。」
