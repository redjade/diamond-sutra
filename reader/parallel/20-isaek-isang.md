# <a name="top"></a>제20분 이색이상분(離色離相分) — 형색과 특징을 떠나다 · 대조

기존 한글 문단과 한문·현토 단위의 수가 다릅니다. 분 전체를 대조하며, 문단과 원문 단위가 일대일로 정렬되었다고 표시하지 않습니다.

## 한글 번역

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 완전한 형색의 몸을 보고 부처를 알아볼 수 있겠느냐?”

수보리가 아뢰었다.

“그렇지 않습니다, 세존이시여. 완전한 형색의 몸으로 여래를 보아서는 안 됩니다.

왜냐하면 여래께서 말씀하신 ‘완전한 형색의 몸’은 완전한 형색의 몸이 아니기 때문입니다. 그러므로 완전한 형색의 몸이라 부르는 것입니다.”

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 모든 훌륭한 특징을 두루 갖춘 모습으로 여래를 알아볼 수 있겠느냐?”

수보리가 아뢰었다.

“그렇지 않습니다, 세존이시여. 모든 특징을 두루 갖춘 모습으로 여래를 보아서는 안 됩니다.

왜냐하면 여래께서 말씀하신 ‘모든 특징을 두루 갖춤’은 두루 갖춤이 아니기 때문입니다. 그러므로 모든 특징을 두루 갖추었다고 부르는 것입니다.”

## 한문과 현토 독음

<a name="source-c20-001"></a>**「須菩提！於意云何？佛可以具足色身見不？」**\
수보리야, 어의운하오. 불을 가이구족색신으로 견부아.

<a name="source-c20-002"></a>**「不也，世尊！如來不應以具足色身見。何以故？如來說具足色身，即非具足色身，是名具足色身。」**\
불야니이다, 세존이시여. 여래를 불응이구족색신으로 견이니이다. 하이고오. 여래가 설구족색신은 즉비구족색신이라, 시명구족색신이니이다.

<a name="source-c20-003"></a>**「須菩提！於意云何？如來可以具足諸相見不？」**\
수보리야, 어의운하오. 여래를 가이구족제상으로 견부아.

<a name="source-c20-004"></a>**「不也，世尊！如來不應以具足諸相見。何以故？如來說諸相具足，即非具足，是名諸相具足。」**\
불야니이다, 세존이시여. 여래를 불응이구족제상으로 견이니이다. 하이고오. 여래가 설제상구족은 즉비구족이라, 시명제상구족이니이다.
