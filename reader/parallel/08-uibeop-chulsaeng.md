# <a name="top"></a>제8분 의법출생분(依法出生分) — 모든 깨달음이 이 가르침에서 나오다 · 대조

기존 한글 문단과 한문·현토 단위의 수가 다릅니다. 분 전체를 대조하며, 문단과 원문 단위가 일대일로 정렬되었다고 표시하지 않습니다.

## 한글 번역

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 어떤 선한 남자나 선한 여자가 삼천대천세계에 가득할 만큼의 일곱 가지 보물을 여래들께 베푼다면, 그 사람이 이루는 복덕이 많겠느냐?”

수보리가 아뢰었다.

“매우 많습니다, 세존이시여.

왜냐하면 이 복덕은 복덕의 본성이 아니기 때문입니다. 그러므로 여래께서는 복덕이 많다고 말씀하십니다.”

세존께서 말씀하셨다.

“그러나 수보리여, 어떤 사람이 이 가르침 가운데 네 구절로 된 게송 하나만이라도 받아 지니고 다른 이에게 자세히 설명해 준다면, 그로 말미암은 복덕이 앞의 복덕보다 훨씬 크고 헤아릴 수 없을 것이다.

왜 그런가? 수보리여, 모든 여래와 가장 높고 바른 깨달음이 바로 이 가르침에서 나오기 때문이다.

수보리여, 이른바 ‘부처의 법’은 곧 부처의 법이 아니다.”

## 한문과 현토 독음

<a name="source-c08-001"></a>**「須菩提！於意云何？若人滿三千大千世界七寶以用布施，**\
「수보리여！ 어의운하인가？ 약인이 만삼천대천세계칠보이용보시하면,

<a name="source-c08-002"></a>**是人所得福德，寧為多不？」**\
시인소득복덕이, 영위다부아？」

<a name="source-c08-003"></a>**須菩提言：「甚多，世尊！何以故？**\
수보리언하되：「심다합니다, 세존이시여！ 하이고인가？

<a name="source-c08-004"></a>**是福德即非福德性，是故如來說福德多。」**\
시복덕은 즉비복덕성이니, 시고로 여래가 설복덕다하십니다。」

<a name="source-c08-005"></a>**「若復有人，於此經中受持，乃至四句偈等，為他人說，其福勝彼。**\
「약부유인이, 어차경중수지하고, 내지사구게등을, 위타인설하면, 기복이 승피하리라.

<a name="source-c08-006"></a>**何以故？須菩提！一切諸佛，及諸佛阿耨多羅三藐三菩提法，皆從此經出。**\
하이고인가？ 수보리여！ 일체제불과, 급제불아뇩다라삼먁삼보리법이, 개종차경출하느니라.

<a name="source-c08-007"></a>**須菩提！所謂佛法者，即非佛法。」**\
수보리여！ 소위불법자는, 즉비불법이니라。」
