# <a name="top"></a>제9분 일상무상분(一相無相分) — 하나의 상도 상으로 붙잡을 수 없음 · 대조

기존 한글 문단과 한문·현토 단위의 수가 다릅니다. 분 전체를 대조하며, 문단과 원문 단위가 일대일로 정렬되었다고 표시하지 않습니다.

## 한글 번역

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 흐름에 든 이가 ‘나는 흐름에 드는 경지를 얻었다’고 생각하겠느냐?”

수보리가 아뢰었다.

“그렇지 않습니다, 세존이시여.

왜냐하면 ‘흐름에 든 이’라 부르지만 실제로 그가 들어간 어떤 법도 없기 때문입니다. 그는 형상에도 들어가지 않고, 소리와 냄새와 맛과 감촉과 마음의 대상에도 들어가지 않습니다. 그러므로 흐름에 든 이라 부릅니다.”

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 한 번 돌아올 이가 ‘나는 한 번 돌아오는 경지를 얻었다’고 생각하겠느냐?”

수보리가 아뢰었다.

“그렇지 않습니다, 세존이시여.

왜냐하면 ‘한 번 돌아올 이’라 부르지만 실제로 오고 감이 없기 때문입니다. 그러므로 한 번 돌아올 이라 부릅니다.”

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 돌아오지 않을 이가 ‘나는 돌아오지 않는 경지를 얻었다’고 생각하겠느냐?”

수보리가 아뢰었다.

“그렇지 않습니다, 세존이시여.

왜냐하면 ‘돌아오지 않을 이’라 부르지만 실제로 옴이 없기 때문입니다. 그러므로 돌아오지 않을 이라 부릅니다.”

세존께서 말씀하셨다.

“수보리여, 너는 어떻게 생각하느냐? 아라한이 ‘나는 아라한의 경지를 얻었다’고 생각하겠느냐?”

수보리가 아뢰었다.

“그렇지 않습니다, 세존이시여.

왜냐하면 아라한이라고 이름 붙일 어떤 법도 실제로 없기 때문입니다. 만일 아라한이 ‘나는 아라한의 경지를 얻었다’고 생각한다면, 곧 나와 사람과 중생과 생명에 집착하는 것입니다.

세존이시여, 부처님께서는 제가 다툼 없는 고요에 머무는 이들 가운데 으뜸이며, 욕망을 떠난 아라한 가운데 으뜸이라고 말씀하셨습니다. 그러나 저는 ‘나는 욕망을 떠난 아라한이다’라고 생각하지 않습니다.

제가 ‘나는 아라한의 경지를 얻었다’고 생각했다면, 세존께서는 수보리가 다툼 없는 고요에 머물기를 좋아하는 이라고 말씀하지 않으셨을 것입니다.

수보리는 실제로 행한다고 할 바가 없기에 ‘다툼 없는 고요에 머무는 수보리’라 불립니다.”

## 한문과 현토 독음

<a name="source-c09-001"></a>**「須菩提！於意云何？須陀洹能作是念：『我得須陀洹果。』不？」**\
「수보리여！ 어의운하인가？ 수다원이 능작시념하되：『아득수다원과하였다。』하겠는가 부아？」

<a name="source-c09-002"></a>**須菩提言：「不也，世尊！何以故？**\
수보리언하되：「불야입니다, 세존이시여！ 하이고인가？

<a name="source-c09-003"></a>**須陀洹名為入流，而無所入，不入色、聲、香、味、觸、法，是名須陀洹。」**\
수다원은 명위입류이나, 이무소입이며, 불입색、성、향、미、촉、법하므로, 시명수다원이라 합니다。」

<a name="source-c09-004"></a>**「須菩提！於意云何？斯陀含能作是念：『我得斯陀含果。』不？」**\
「수보리여！ 어의운하인가？ 사다함이 능작시념하되：『아득사다함과하였다。』하겠는가 부아？」

<a name="source-c09-005"></a>**須菩提言：「不也，世尊！何以故？**\
수보리언하되：「불야입니다, 세존이시여！ 하이고인가？

<a name="source-c09-006"></a>**斯陀含名一往來，而實無往來，是名斯陀含。」**\
사다함은 명일왕래이나, 이실무왕래이므로, 시명사다함이라 합니다。」

<a name="source-c09-007"></a>**「須菩提！於意云何？阿那含能作是念：『我得阿那含果。』不？」**\
「수보리여！ 어의운하인가？ 아나함이 능작시념하되：『아득아나함과하였다。』하겠는가 부아？」

<a name="source-c09-008"></a>**須菩提言：「不也，世尊！何以故？**\
수보리언하되：「불야입니다, 세존이시여！ 하이고인가？

<a name="source-c09-009"></a>**阿那含名為不來，而實無來，是故名阿那含。」**\
아나함은 명위불래이나, 이실무래이므로, 시고로 명아나함이라 합니다。」

<a name="source-c09-010"></a>**「須菩提！於意云何？阿羅漢能作是念：『我得阿羅漢道。』不？」**\
「수보리여！ 어의운하인가？ 아라한이 능작시념하되：『아득아라한도하였다。』하겠는가 부아？」

<a name="source-c09-011"></a>**須菩提言：「不也，世尊！何以故？實無有法名阿羅漢。**\
수보리언하되：「불야입니다, 세존이시여！ 하이고인가？ 실무유법명아라한이니이다.

<a name="source-c09-012"></a>**世尊！若阿羅漢作是念：『我得阿羅漢道。』即為著我、人、眾生、壽者。**\
세존이시여！ 약아라한이 작시념하되：『아득아라한도하였다。』하면 즉위착아、인、중생、수자입니다.

<a name="source-c09-013"></a>**世尊！佛說我得無諍三昧人中最為第一，是第一離欲阿羅漢。**\
세존이시여！ 불께서 설아득무쟁삼매인중최위제일이라 하셨으니, 시제일이욕아라한입니다.

<a name="source-c09-014"></a>**我不作是念：『我是離欲阿羅漢。』**\
아부작시념하되：『아시이욕아라한이다。』하지 않습니다.

<a name="source-c09-015"></a>**世尊！我若作是念：『我得阿羅漢道。』**\
세존이시여！ 아약작시념하되：『아득아라한도하였다。』하면,

<a name="source-c09-016"></a>**世尊則不說須菩提是樂阿蘭那行者。**\
세존께서 즉불설수보리시요아란나행자라 하셨으리이다.

<a name="source-c09-017"></a>**以須菩提實無所行，而名須菩提是樂阿蘭那行。」**\
이수보리실무소행이므로, 이명수보리시요아란나행이라 하셨나이다。」
