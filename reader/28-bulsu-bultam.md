# <a name="top"></a>제28분 불수불탐분(不受不貪分) — 복덕을 받아도 탐착하지 않다

## <a name="translation"></a>한글 번역

세존께서 말씀하셨다.

“수보리여, 어떤 보살이 갠지스강의 모래알 수만큼 많은 세계를 일곱 가지 보물로 가득 채워 여래들께 베풀더라도, 또 다른 보살이 모든 것에 자아가 없고 생겨남도 없다는 진리를 흔들림 없이 받아들인다면, 이 보살의 복덕이 앞의 보살이 얻은 복덕보다 뛰어나다.

수보리여, 보살들은 복덕을 자기 것으로 받아 지니지 않기 때문이다.”

수보리가 아뢰었다.

“세존이시여, 보살이 복덕을 받아 지니지 않는다는 것은 무슨 뜻입니까?”

세존께서 말씀하셨다.

“수보리여, 보살은 자신이 지은 복덕을 탐내어 붙잡아서는 안 된다. 그러므로 복덕을 받아 지니지 않는다고 말한다.”

## <a name="notes"></a>번역 주

1. <a name="c28-note-01"></a>`一切法無我`는 사람에게 영원한 자아가 없다는 말에 그치지 않고, 모든 현상에 독립되고 불변하는 본질이 없다는 뜻이다. 여기서 `法`은 가르침만이 아니라 경험되는 모든 현상을 가리킨다.

2. <a name="c28-note-02"></a>`忍`에 해당하는 산스크리트 `kṣānti`는 단순히 고통을 참는 인내가 아니다. 진리를 거스르지 않고 깊이 받아들여 흔들리지 않는 확고함을 뜻한다.

3. <a name="c28-note-03"></a>산스크리트본에는 이 보살이 `자아가 없고 생겨남이 없는 모든 법`에 대한 확고한 받아들임을 얻는다는 표현이 있다. 구마라집본에는 `모든 법이 무아임을 알고 인을 이룬다`는 표현이 있다. 본문의 `생겨남도 없다`는 구마라집본에 없는 산스크리트본의 `anutpattika`를 보완한 것이다. 2026-10-30 교정에서 본문의 `고정된`은 C의 `無我`와 S의 `nirātmaka`에 맞춰 덜었다.

4. <a name="c28-note-04"></a>`不受福德`은 선행에 결과가 없거나 보살이 복덕을 거부해야 한다는 뜻이 아니다. 이어지는 문장이 직접 설명하듯, 자신이 지은 복덕을 소유물이나 보상으로 탐착하지 않는다는 뜻이다.

5. <a name="c28-note-05"></a>산스크리트본은 `parigrahītavyaḥ ... no grahītavyaḥ`, 곧 같은 어근 √`grah`에 `pari-` 접두사가 붙은 말과 붙지 않은 말을 대조하여 복덕을 `받아들여야 하지만 붙잡아서는 안 된다`고 설명한다. 복덕의 인과는 받아들이되 그것을 고정된 자기 몫으로 움켜쥐지 않는다는 뜻이다. 구마라집본에는 `不受`와 `不應貪著`의 문답이 있다.

6. <a name="c28-note-06"></a>산스크리트본은 일곱 가지 보물을 `tathāgatebhyo 'rhadbhyaḥ samyaksaṃbuddhebhyaḥ`에게 베푼다고 명시한다. 이는 서로 다른 세 집단이라기보다 여래들을 `아라한이며 바르게 깨달은 이들`이라고 꾸미는 존칭의 나열로 읽었다. 구마라집본에는 받는 이가 생략되어 있으며, 본문의 `여래들께`는 산스크리트본에서 보완한 것이다.

## <a name="source"></a>한문과 현토 독음

<a name="source-c28-001"></a>**「須菩提！若菩薩以滿恒河沙等世界七寶布施，**\
“수보리야！약보살이 이만항하사등세계칠보로 보시하고，

<a name="source-c28-002"></a>**若復有人知一切法無我，得成於忍，此菩薩勝前菩薩所得功德。**\
약부유인이 지일체법무아하여 득성어인하면，차보살은 승전보살소득공덕하리라。

<a name="source-c28-003"></a>**須菩提！以諸菩薩不受福德故。」**\
수보리야！이제보살불수복덕고니라。”

<a name="source-c28-004"></a>**須菩提白佛言：「世尊！云何菩薩不受福德？」**\
수보리가 백불언하되：“세존이시여！운하보살불수복덕이니이까？”

<a name="source-c28-005"></a>**「須菩提！菩薩所作福德，不應貪著，是故說不受福德。」**\
“수보리야！보살소작복덕을 불응탐착일새，시고설불수복덕이니라。”
