# <a name="top"></a>제30분 일합이상분(一合理相分) — 하나로 합쳐졌다는 관념

## <a name="translation"></a>한글 번역

세존께서 말씀하셨다.

“수보리여, 어떤 선한 남자나 선한 여자가 삼천대천세계를 부수어 미세한 티끌로 만든다면, 너는 어떻게 생각하느냐? 그 티끌의 무더기가 많겠느냐?”

수보리가 아뢰었다.

“매우 많습니다, 세존이시여.

왜냐하면 그 티끌의 무더기가 실제로 있다면, 부처님께서는 그것을 티끌의 무더기라고 말씀하지 않으셨을 것이기 때문입니다. 부처님께서 티끌의 무더기라고 말씀하신 것은 티끌의 무더기가 아닙니다. 그러므로 티끌의 무더기라 부릅니다.

세존이시여, 여래께서 말씀하신 삼천대천세계도 세계가 아닙니다. 그러므로 세계라 부릅니다.

왜냐하면 세계가 실제로 있다면, 그것은 하나의 덩어리로 붙잡은 것일 터이기 때문입니다. 여래께서 하나의 덩어리로 붙잡는다고 말씀하셨지만, 그것은 붙잡음이 아닙니다. 그러므로 하나의 덩어리로 붙잡는다고 부릅니다.”

세존께서 말씀하셨다.

“수보리여, 하나의 덩어리로 붙잡는다는 것은 말로 나타낼 수 없다. 다만 범부들이 그것에 탐착할 뿐이다.”

## <a name="notes"></a>번역 주

1. <a name="c30-note-01"></a>티끌과 세계는 서로 반대되는 두 실체가 아니다. 세계는 수많은 조건과 부분을 의지해 세계라 불리고, 티끌 또한 더는 나눌 수 없는 독립된 실체로 확정되지 않는다.

2. <a name="c30-note-02"></a>산스크리트본의 비유는 구마라집본보다 규모가 크다. 삼천대천세계에 있는 티끌 수만큼의 세계를 다시 미세한 원자로 만들 경우를 묻지만, 구마라집본은 하나의 삼천대천세계를 티끌로 부순다고 간결하게 옮긴다.

3. <a name="c30-note-03"></a>`一合相`은 여러 요소가 모여 하나의 단단한 전체를 이룬다는 관념이다. 산스크리트 `piṇḍagrāha`는 `한 덩어리로 붙잡음`이라는 뜻이고, 이어서 그것을 `agrāha`, 곧 붙잡음이 아니라고 부정한다. 이 어근의 반복을 살리기 위해 본문을 `하나의 덩어리로 붙잡음`으로 고쳤다. 이것을 독립된 하나의 실체로 취할 수 없다는 뜻은 주석에서만 풀이했다.

4. <a name="c30-note-04"></a>`不可說`은 세계에 관해 아무 말도 해서는 안 된다는 뜻이 아니다. `세계`나 `하나`라는 이름은 일상에서 쓸 수 있지만, 그 이름에 대응하는 독립된 실체를 말로 나타낼 수 없다는 뜻이다. 산스크리트본은 이를 `avyavahāra`와 `anabhilāpya`라고 하고, 다시 `법도 아니고 법 아닌 것도 아니다`라고 덧붙이지만 이 마지막 문구는 구마라집본에 없다.

5. <a name="c30-note-05"></a>마지막의 `貪著其事`는 범부가 일상의 사물을 경험한다는 사실을 탓하지 않는다. 조건의 모임을 독립된 실재로 여기고 거기에 매달리는 것을 가리킨다.

“심다하나이다，세존이시여！하이고오？약시미진중이 실유자면，불즉불설시미진중이시리라。

<a name="source-c30-004"></a>**所以者何？佛說微塵眾，則非微塵眾，是名微塵眾。**\

<a name="source-c30-005"></a>**世尊！如來所說三千大千世界，則非世界，是名世界。**\

<a name="source-c30-006"></a>**何以故？若世界實有者，則是一合相。**\

여래설일합상은 즉비일합상일새，시명일합상이니이다。”
