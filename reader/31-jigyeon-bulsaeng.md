# <a name="top"></a>제31분 지견불생분(知見不生分) — 앎과 봄에도 관념을 내지 않다

## <a name="translation"></a>한글 번역

세존께서 말씀하셨다.

“수보리여, 어떤 사람이 ‘부처님께서 나라는 견해, 사람이라는 견해, 중생이라는 견해, 생명이라는 견해를 말씀하셨다’고 한다면, 너는 어떻게 생각하느냐? 그 사람이 내가 말한 뜻을 이해한 것이겠느냐?”

수보리가 아뢰었다.

“그렇지 않습니다, 세존이시여. 그 사람은 여래께서 말씀하신 뜻을 이해하지 못한 것입니다.

왜냐하면 세존께서 말씀하신 나라는 견해, 사람이라는 견해, 중생이라는 견해, 생명이라는 견해는 그런 견해들이 아니기 때문입니다. 그러므로 나라는 견해, 사람이라는 견해, 중생이라는 견해, 생명이라는 견해라 부릅니다.”

세존께서 말씀하셨다.

“수보리여, 가장 높고 바른 깨달음을 향한 마음을 낸 이는 모든 것을 이와 같이 알고, 이와 같이 보며, 이와 같이 믿고 이해하되, 어떤 법이라는 관념도 내지 않아야 한다.

수보리여, 이른바 법이라는 관념을 여래는 법이라는 관념이 아니라고 말한다. 그러므로 법이라는 관념이라 부르는 것이다.”

## <a name="notes"></a>번역 주

1. <a name="c31-note-01"></a>앞에서 반복된 `我相·人相·衆生相·壽者相`이 여기서는 `見`, 곧 견해로 나타난다. 나·사람·중생·생명을 고정된 실체로 보는 관점을 말하며, 단순히 그런 단어를 사용하는 것 자체를 금하는 것은 아니다.

2. <a name="c31-note-02"></a>`即非…是名…`의 구조는 그릇된 견해가 아예 없다고 부정하는 말이 아니다. 그 견해조차 독립되고 변하지 않는 실체로 다시 붙잡지 않으면서, 관습적인 이름으로는 견해라고 부른다는 뜻이다.

3. <a name="c31-note-03"></a>`知·見·信解`는 지적인 앎, 직접적인 봄, 신뢰를 동반한 이해를 함께 말한다. 깨달음을 향한 이는 모든 현상을 이와 같이 이해하면서도 자신의 이해를 또 하나의 고정된 관념으로 만들지 않는다.

4. <a name="c31-note-04"></a>산스크리트본은 법이라는 관념뿐 아니라 `법이 아니라는 관념`에도 머물지 말라고 명시한다. 구마라집본의 `不生法相`은 어느 한쪽을 실체화하지 않는 이 뜻을 간결하게 담는다.

5. <a name="c31-note-05"></a>여기서 `法相`은 모든 현상에 나타나는 일반적인 특징이라는 후대 논서의 전문 용법보다, 무엇을 `법`이라고 규정하여 붙잡는 관념에 가깝다.

6. <a name="c31-note-06"></a>2026-10-30 교정: 마지막 문장의 `여래가 말한 법의 관념이 아니다`는 여래가 뜻한 참된 법의 관념이 따로 있다는 뜻으로 읽힐 수 있어, T235의 `如來說即非法相`과 S의 `asaṃjñaiṣā tathāgatena bhāṣitā`에 맞춰 `여래는 법이라는 관념이 아니라고 말한다`로 고쳤다. `법의 관념`과 `법이라는 관념`의 표기도 하나로 맞췄다.

## <a name="source"></a>한문과 현토 독음

<a name="source-c31-001"></a>**「須菩提！若人言：『佛說我見、人見、眾生見、壽者見。』**\
“수보리야！약인언호되：‘불설아견、인견、중생견、수자견이라。’하면，

<a name="source-c31-002"></a>**須菩提！於意云何？是人解我所說義不？」**\
수보리야！어의운하오？시인이 해아소설의부아？”

<a name="source-c31-003"></a>**「世尊！是人不解如來所說義。何以故？**\
“세존이시여！시인은 불해여래소설의니이다。하이고오？

<a name="source-c31-004"></a>**世尊說我見、人見、眾生見、壽者見，即非我見、人見、眾生見、壽者見，**\
세존설아견、인견、중생견、수자견은 즉비아견、인견、중생견、수자견일새，

<a name="source-c31-005"></a>**是名我見、人見、眾生見、壽者見。」**\
시명아견、인견、중생견、수자견이니이다。”

<a name="source-c31-006"></a>**「須菩提！發阿耨多羅三藐三菩提心者，於一切法，**\
“수보리야！발아뇩다라삼먁삼보리심자는 어일체법에，

<a name="source-c31-007"></a>**應如是知，如是見，如是信解，不生法相。**\
응여시지하며，여시견하며，여시신해하여，불생법상이니라。

<a name="source-c31-008"></a>**須菩提！所言法相者，如來說即非法相，是名法相。」**\
수보리야！소언법상자는 여래설 즉비법상일새，시명법상이니라。”
