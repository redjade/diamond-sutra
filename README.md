# 금강경

한글 번역을 이어 읽고 같은 문서 아래에서 주석과 한문·현토를 살펴봅니다. 기존 수록 범위와 문구·독서 구분을 보존한 번역·검토 중의 초안입니다.

## 읽기

**[32분 읽기 목록](reader/README.md)** · [제1분부터 읽기](reader/01-beophoe-inyu.md)
