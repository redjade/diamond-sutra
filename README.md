# 금강경 번역 프로젝트

수지독송을 위한 새로운 한국어 《금강경》 번역을 만드는 작업 공간이다.

현재 **교정 중인 번역 초안**이다. 32분의 번역·번역 주·한문과 현토 독음을 수록했으며, 2026-10-16에 지정한 한문·산스크리트 전자본을 기준으로 모든 분의 전 구절 대조 검토를 마쳤다. 한글 번역에는 산스크리트를 바탕으로 한 보완과 해석이 있으므로 한문만의 직역과는 차이가 있다. 다른 사본까지 교감한 확정 번역은 아니며, 오류나 판본에 관한 제안은 GitHub 이슈로 남길 수 있다.

## 기본 방침

- 산스크리트 《Vajracchedikā Prajñāpāramitā》를 의미 확인의 기준으로 삼는다.
- 구마라집 한역 《金剛般若波羅蜜經》(T235)을 독송 전통의 기준으로 삼는다.
- 어느 한쪽에만 있는 표현은 억지로 합치지 않고 번역 주에 밝힌다.
- 본문은 소리 내어 읽기 쉬운 한국어로 쓴다. 원문에 없는 해설은 주석으로 분리하는 것을 원칙으로 하고, 본문에 남긴 해석적 보충은 검토 기록에 밝힌다.
- 이해와 일상 수행을 위한 글은 본문 번역과 분리해 작성한다.

## 판본

- 한문: 구마라집 역, 《大正新脩大藏經》 T08, No. 235
- 산스크리트 대조본: P. L. Vaidya 편집본(1961)
- 산스크리트 공개 도메인 참고본: F. Max Müller 편집본(1881)

독송용 한문은 CBETA T235의 교감 주본문을 따른다. 설법의 산문과 게송을 수록하고 제목·역자 표시·권말 부가 진언은 본문에서 제외했다. 표점과 문단 나눔은 읽기 편하게 조정했다. 이번 확인에 사용한 고정 커밋과 세부 범위는 [SOURCES.md](SOURCES.md)에 기록했다.

### 원전 링크와 이용 조건

- [CBETA T235 XML](https://github.com/cbeta-org/xml-p5/blob/master/T/T08/T08n0235.xml): 구마라집 한역의 기준본으로 사용한다. CBETA 전자자료는 비영리 용도로 사용하고, 재사용할 때 원본 XML 헤더와 출처 정보를 보존한다.
- [Wikisource 구마라집본](https://zh.wikisource.org/zh/%E9%87%91%E5%89%9B%E8%88%AC%E8%8B%A5%E6%B3%A2%E7%BE%85%E8%9C%9C%E7%B6%93_(%E9%B3%A9%E6%91%A9%E7%BE%85%E4%BB%80)): 사람이 읽고 대조하기 편한 한문본이다. Wikisource의 텍스트는 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ko) 조건에 따라 이용한다.
- F. Max Müller, *Buddhist Texts from Japan* (1881): 공개 도메인 산스크리트 교정본의 스캔은 [Open Library](https://openlibrary.org/books/OL20617692M/Buddhist_Texts_from_Japan)와 [Google Books](https://books.google.com/books/about/Buddhist_texts_from_Japan_ed_by_F_M_M%C3%BCl.html?id=v8wOAAAAQAAJ)에서 확인한다.
- [DSBC 로마자 산스크리트본](https://www.dsbcproject.org/canon-text/content/76/633): 문구와 판본을 연구·대조하는 용도로만 사용한다. 전문을 이 저장소에 옮기지 않으며, 복제나 재배포가 필요할 때에는 [DSBC 이용 정책](https://www.dsbcproject.org/public/pages/usage-policy)을 먼저 따른다.
- [GRETIL의 Vaidya본](https://gretil.sub.uni-goettingen.de/gretil/1_sanskr/4_rellit/buddh/bsu051_u.htm): P. L. Vaidya 편집본을 검색하고 대조하는 참고 자료이다. 원문 파일에 표시된 출처와 이용 조건을 준수한다.

이 저장소에는 산스크리트 전문을 복제하여 저장하지 않는다. 필요한 문구는 위 원전에서 대조하고, 번역문과 번역 주에는 판본 판단에 필요한 범위만 반영한다.

번역을 다듬을 때에는 구절별 한문과 산스크리트 대응어, 선택한 표현과 이유, 다른 해석, 배경 자료, 관련 판본, 실제 확인일과 URL을 `SOURCES.md`와 여기서 연결한 `review/`의 분별 검토표에 함께 갱신한다. 현대 저자의 수행적 해석을 참조할 경우 문헌적 대응어와 구별하여 저자와 근거를 기록한다.

### 빨리어 자료에 관하여

《금강경》은 산스크리트계 대승 반야경전이며, 금강경에 해당하는 빨리어 원문이나 전승된 빨리어 완본은 없다. 따라서 빨리어 자료를 금강경의 원문이라고 표시하지 않는다. 향후 무아, 집착의 내려놓음, 보시 등 주제가 맞닿는 빨리어 경전의 평행 가르침은 금강경 본문과 구별하여 별도의 참고 자료로 연결할 수 있다.

## 진행 상황

아래 체크 표시는 각 분의 초안 작성 완료를 뜻한다. 모든 사본의 교감과 번역 확정을 뜻하지 않는다. 2026-10-15의 구조·한문 검사와 주요 용어 검토에 이어, 2026-10-16에는 32분 전 구절을 427개 의미 단위로 나누어 C·S 전자본과 대조했다. 부정의 범위, 주어·시제·수량, 원문에 없는 조건, 판본별 추가·차이를 점검하고 25개 분의 번역 또는 주석을 고쳤다. 수정하지 않은 7개 분도 검토표에 유지 근거를 남겼다. 다른 사본·교정본 확인과 현토 문체 통일은 별도의 후속 과제다.

## 문서 검증

프로젝트 디렉터리에서 다음 명령을 실행한다. 별도 Python 패키지는 필요하지 않다.

```powershell
uv run python scripts/verify_translation.py
uv run python scripts/verify_translation.py --cbeta
```

첫 명령은 32분의 번호·섹션·한문과 독음의 짝을 검사한다. 두 번째 명령은 네트워크로 고정 커밋의 CBETA 원문을 읽어 한자열을 대조한다. 검사는 번역 의미의 정확성까지 보증하지 않는다.
