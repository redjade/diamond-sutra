- C: [CBETA T235 고정본](https://github.com/cbeta-org/xml-p5/blob/dbdea41071e1e260ad84b72faefd4587333cf76d/T/T08/T08n0235.xml), 0748c24–0749a04.
- S: [GRETIL Vaidya 전자본](https://gretil.sub.uni-goettingen.de/gretil/1_sanskr/4_rellit/buddh/bsu051_u.htm), §2, 표시 쪽 75. 직접 본 자료는 전자본이다.

| 구절 | S 대응 표지 | 판정과 번역 판단 |

| 時長老須菩提在大眾中 | āyuṣmat, Subhūti, parṣad | 유지. `장로 수보리`는 C, S의 존칭은 존자에 가까움. 같은 인물로 처리한다. |
| 即從座起 | utthāya āsanāt | 유지. 자리에서 일어남. |
| 偏袒右肩 | ekāṃsam uttarāsaṅgam | 유지. 한쪽 어깨의 가사를 정리함을 C에 따라 오른쪽 어깨를 드러냄으로 구체화한다. |
| 右膝著地 | dakṣiṇa jānumaṇḍala, pṛthivī | 유지. 오른쪽 무릎을 땅에 댐. |
| 合掌恭敬而白佛言 | añjali, praṇamya, avocat | 유지. 합장·공경·여쭘의 행위를 모두 반영한다. |
| 希有世尊 | āścarya, paramāścarya, bhagavan, sugata | 유지. S의 찬탄·존칭 반복은 한국어에서 압축했다. |
| 善護念諸菩薩 | anugraha, anuparigṛhīta | 유지. 돌보고 보살핌을 `지극히 보살펴 주심`으로 풀이한다. |
| 善付囑諸菩薩 | parīndanā, parīndita | 교정. `그 길을 온전히 맡김`을 `가르침을 잘 당부함`으로 고쳤다. 당부·위탁의 범위를 문맥에 따라 풀었음을 주석에 명시했다. |
| 善男子善女人發…心 | kulaputra, kuladuhitṛ, bodhisattvayānasaṃprasthita | 유지. C의 발심을 번역하고 S의 보살승에 나섬과 연결한다. 신분이나 출신 집단을 본문에 새로 한정하지 않는다. |
| 應云何住 | sthātavyam | 유지. 당위의 질문 `어떻게 머물러야`. |
| S에만 있는 수행 질문 | pratipattavyam | 보완 유지. 세 질문을 모두 반영한 사실을 주석에 표시했다. |
| 云何降伏其心 | cittaṃ pragrahītavyam | 유지. 억압이나 생각 제거로 좁히지 않는 `마음을 다스림`. |
| 善哉善哉如汝所說 | sādhu, evam etat | 유지. 찬탄과 동의를 각각 반영한다. |

| 汝今諦聽當為汝說 | śṛṇu, manasi kuru, bhāṣiṣye | 보완 유지. `자세히 듣기`와 S의 주의를 기울임을 함께 옮겨 `마음에 깊이 새겨라`라고 했음을 주석에 밝혔다. 미래의 설법 예고를 유지한다. |
| 應如是住如是降伏 | yathā sthātavyam 등 | 판본 구별. C는 직접 당부, S는 어떻게 해야 하는지 설하겠다는 예고. 본문은 S의 문장 구조를 채택했다. |
| 唯然願樂欲聞 | evam bhagavan, pratyaśrauṣīt | 유지. C의 기꺼이 듣겠다는 청을 살렸다. S의 짧은 동의보다 긴 응답이다. |

한문·현토 8쌍을 확인했다. `마하살`, 여래의 여러 존칭을 한국어에서 압축한 범위도 주석에 밝혔다. `고정된` 보충은 없다. 부촉의 세부 교학적 범위는 다른 주석과 대조할 여지가 있으나, 원문에 없는 `길`의 이전·위임은 덜어 냈다.
