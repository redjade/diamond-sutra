# 제22분 무법가득분 전 구절 대조 검토

- 한문 기준: [CBETA T08 No.235 고정 커밋 XML](https://raw.githubusercontent.com/cbeta-org/xml-p5/dbdea41071e1e260ad84b72faefd4587333cf76d/T/T08/T08n0235.xml), 대정장 0751c20–0751c23
- 산스크리트 대조: [GRETIL Vaidya본](https://gretil.sub.uni-goettingen.de/gretil/1_sanskr/4_rellit/buddh/bsu051_u.htm) §22, Vaidya 86–87
- 인쇄본은 직접 대조하지 않았다.

| 한문 표지 | S 대응어 | 판정 | 근거와 수정 |
|---|---|---|---|
| 須菩提白佛言 | S에서는 세존이 먼저 질문 | 유지+주 보강 | C와 S는 화자와 문답 순서가 다르다. 본문은 C를 따르며 새 주 4에 차이를 명시했다. |
| 佛得…為無所得耶 | S 질문 `asti ... dharmaḥ ... tathāgatena ... abhisaṃbuddhaḥ?`와 수보리의 부정 | 유지 | C의 질문은 `깨달았으나 얻은 것이 없음`을 확인한다. 본문이 `실은 얻은 것이 없다는 말씀입니까`로 정확히 살렸다. |
| 如是如是 | `evam etat ... evam etat` | 유지 | S에서는 수보리의 부정을 세존이 확인하는 말이고, C에서는 수보리 질문에 대한 긍정이다. 같은 어구지만 담화 기능 차이를 주 4가 밝힌다. |
| 乃至無有少法可得 | `aṇur api ... dharmo na saṃvidyate nopalabhyate` | 유지 | `가장 작은 법 하나조차 얻을 것이 없다`가 핵심이다. S는 `존재하지도 않고 인식·획득되지도 않는다`는 두 술어를 쓰며 주 2가 이를 보완한다. |
| 是名阿耨多羅三藐三菩提 | `tenocyate anuttarā samyaksaṃbodhiḥ` | 유지 | 얻을 대상으로 성립하지 않으므로 그 이름을 쓴다는 정형구를 보존한다. |

## 최종 판단

- 번역 본문은 유지하고 판본의 화자·문답 순서 차이를 번역 주 1곳에 추가했다. 현토의 질문형 어미 오기 `야이니까`는 `야이까`로 바로잡았다.
- C에만 있는 `무소득입니까` 형태와 S에만 있는 수보리의 명시적 부정 응답은 서로 합성하지 않고 C 중심 본문으로 유지했다.
